# Case Study: Telecom SIM Activation Data Ingestion Using Azure Function and Snowflake

## Problem Statement

A telecom company launches a new prepaid SIM activation portal. Customers can activate SIM cards through the company's website.

Currently, activation requests are stored in a CSV file and manually loaded into Snowflake by the operations team, causing delays in customer onboarding and reporting.

The company wants to automate this process by using an Azure Function that receives activation requests through an API and directly stores them in Snowflake.

The solution should:

* Receive customer activation details through an HTTP request.
* Validate mandatory fields.
* Insert the activation record into Snowflake.
* Return a success or failure response to the calling application.
* Allow business teams to query activation data immediately from Snowflake.

---

## Business Requirements

When a customer activates a SIM card, the following information should be captured:

* Customer Name
* Mobile Number
* Plan Name
* Circle/Region
* Activation Date
* Activation Status

The activation data must be stored in Snowflake in near real time.

## Azure Function Code

```python
import azure.functions as func
import snowflake.connector
import json
from datetime import datetime

def main(req: func.HttpRequest) -> func.HttpResponse:

    try:

        body = req.get_json()

        customer_name = body["customer_name"]
        mobile_number = body["mobile_number"]
        plan_name = body["plan_name"]
        circle = body["circle"]
        status = body["status"]

        conn = snowflake.connector.connect(
            user='TELECOM_USER',
            password='Password123',
            account='your_account',
            warehouse='COMPUTE_WH',
            database='TELECOM_DB',
            schema='OPERATIONS'
        )

        cur = conn.cursor()

        cur.execute("""
        INSERT INTO SIM_ACTIVATIONS
        (
            CUSTOMER_NAME,
            MOBILE_NUMBER,
            PLAN_NAME,
            CIRCLE,
            ACTIVATION_DATE,
            STATUS
        )
        VALUES (%s,%s,%s,%s,%s,%s)
        """,
        (
            customer_name,
            mobile_number,
            plan_name,
            circle,
            datetime.now(),
            status
        ))

        conn.commit()

        cur.close()
        conn.close()

        return func.HttpResponse(
            "Activation saved successfully",
            status_code=200
        )

    except Exception as e:

        return func.HttpResponse(
            str(e),
            status_code=500
        )
```
