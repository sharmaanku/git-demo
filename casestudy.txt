# Case Study Problem Statement: Telecom Customer Usage Data Pipeline using Azure Data Factory, Databricks, and Snowflake

A leading telecommunications company, **TeleConnect Communications**, operates across multiple regions and serves millions of customers. Every day, various operational systems generate customer-related data such as call records, internet usage, SMS transactions, recharge activities, and customer profile information. The business wants to centralize this data in **Snowflake** for enterprise reporting, customer analytics, revenue analysis, and operational monitoring.

Currently, data files are delivered daily to cloud storage, but the ingestion process is manual and time-consuming. The organization wants to automate the entire workflow using **Azure Data Factory (ADF)** and **Azure Databricks**.

The proposed solution should use **Azure Data Factory** to orchestrate the pipeline and trigger a **Databricks notebook**. The Databricks notebook should read the source files, perform basic validations such as null checks and data type verification, and then load the processed data into Snowflake tables. Once the data is successfully loaded, Snowflake should serve as the centralized analytics platform for downstream reporting and business intelligence applications.

The solution must support daily data loads, maintain auditability, provide failure notifications, and ensure that the latest telecom data is available in Snowflake for analytical consumption.

# Expected Workflow

1. Daily telecom data files arrive in Azure Data Lake Storage.
2. Azure Data Factory detects the files and triggers the Databricks notebook.
3. Databricks reads all telecom source files.
4. Databricks performs basic validation:

   * Mandatory field checks
   * Null value checks
   * Data type verification
   * Duplicate record detection
5. Processed data is loaded into Snowflake tables:

   * CUSTOMER_MASTER
   * CALL_USAGE
   * INTERNET_USAGE
   * RECHARGE_TRANSACTIONS
6. Azure Data Factory captures execution status and logs.
7. Business users access the latest telecom data from Snowflake for reporting and analytics.

This case study focuses on **ADF orchestration → Databricks notebook execution → Snowflake data loading** in a realistic telecom business scenario.
